# How to Enable WebAssembly (WASM) in Google Chrome

WebAssembly (WASM) is enabled by default in most modern versions of Google Chrome.  
However, if you need to verify or manually enable it, follow these steps:

---

## 1. Check Chrome Version
Make sure you’re using Chrome **57 or later**, since WebAssembly support was introduced in Chrome 57.  
To check your version:
1. Open Chrome.
2. Go to `chrome://settings/help`.

---

## 2. Enable WASM in Chrome Flags (if needed)
1. Open a new tab in Chrome.
2. Go to:  `chrome://flags/#enable-experimental-webassembly-features`

3. If the flag exists, set it to **Enabled**.
4. Restart Chrome.

> ⚠️ In the latest Chrome versions, WebAssembly is enabled by default and the flag may no longer appear.
